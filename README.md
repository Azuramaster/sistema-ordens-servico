# Sistema de Controle de Ordens de Serviço

Sistema de gerenciamento de clientes, técnicos e ordens de serviço desenvolvido em Python para prática de Programação Orientada a Objetos.

## Sobre o projeto

O sistema permite o gerenciamento de:

- Clientes
- Técnicos
- Ordens de Serviço

O objetivo do projeto é praticar modelagem orientada a objetos e evoluir gradualmente para um sistema mais completo.

---

## Funcionalidades da V1

### Clientes

- Cadastro
- Consulta
- Alteração
- Remoção

### Técnicos

- Cadastro
- Consulta
- Alteração
- Remoção

### Ordens de Serviço

- Criação
- Associação de técnico
- Consulta
- Cancelamento
